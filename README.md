Проект разработан для Всероссийского хакатона **«Идея фикс»** (номинация *«Продвинутая разработка»*).

## 🌟 О проекте

**«Лига Помощников»** — геймифицированная платформа взаимной помощи для учебных классов в мессенджере **MAX**:
* 💬 **Учебные вопросы в чате:** Школьники задают вопросы по учёбе через команду `/ask <вопрос>`.
* 🤝 **Взаимовыручка реплаем:** Одноклассники отвечают на вопрос обычным реплаем (Reply).
* ✅ **Личное подтверждение:** Автор вопроса подтверждает помощь в личном диалоге с ботом кнопками `[ ✅ Помог ]` или `[ ❌ Не помог ]`.
* 🪙 **Спасибки и опыт:** Помощник получает +50 XP и +1 «спасибку» 🪙, открывает достижения и продвигается по лестнице званий (от *Новичка* до *Легенды школы*).
* 🔥 **Стрик дней помощи:** Механика непрерывных серий побуждает ребят регулярно заходить и помогать одноклассникам.
* 📈 **Аналитика «Пульс класса» в профиле учителя:** Педагог видит статистику решённых вопросов за неделю, процент самостоятельных решений, экономию своего рабочего времени в часах и лидера недели вместо пустых ученических счётчиков.
* 🏆 **Пятничный авто-дайджест:** Каждую пятницу бот автоматически подводит итоги недели в групповом чате с награждением лучших помощников.
* 🎁 **Школьная лавка наград:** Ученики обменивают накопленные спасибки на бонусы от учителей (освобождение от одного устного ДЗ, выбор соседа по парте и др.).
* 🎓 **Ролевой Кабинет учителя:** Автоматическое скрытие вкладки покупок «Лавка» и отображение специализированных инструментов наставника: журнал заявок с историей выдачи, создание наград чата и персональное поощрение бейджем «Выбор учителя» (+20 спасибок).
* 🖼 **Подтягивание аватаров из MAX:** WebApp автоматически отображает реальный аватар и имя пользователя из мессенджера MAX.
* 🏫 **Мульти-классовость:** Полная изоляция спасибок, наград и заявок по каждому учебному чату.

* **Среда и язык:** Python 3.11+ / 3.14
* **Бэкенд:** FastAPI, Uvicorn, SQLModel / SQLAlchemy 2.0 (async), Pydantic v2

* **Инфраструктура:** Docker, Docker Compose, Nginx (Let's Encrypt SSL)

## 🚀 Быстрый запуск

### 1. Подготовка конфигурации
Скопируйте пример файла окружения:
```bash
cp .env.example .env
```
Укажите токен вашего бота в переменной `MAX_BOT_TOKEN`.

### 2. Запуск через Docker Compose (рекомендуется)
```bash
docker compose up -d --build
docker compose logs -f
```

### 3. Запуск без Docker
```bash
python3 -m venv venv
source venv/bin/activate
pip install -r requirements.txt
python3 main.py
```
Приложение доступно по адресу `http://localhost:8000/`.

## 📱 Управление в боте и команды

### В личном диалоге с ботом
* `[ ❓ Как спросить? ]` — инструкция по формату вопросов и ответов
* `[ 👤 Мой профиль ]` — просмотр звания, уровня, опыта и спасибок
* `[ 🪙 Баланс спасибок ]` / `/balance` — баланс спасибок с детализацией по каждому активному учебному чату

### В групповом чате класса
* `/ask <вопрос>` — задать учебный вопрос классу
* Реплай на вопрос — предложить решение или подсказку
* `/top` — топ-10 помощников класса за текущий период
* `/digest` — публикация сводки итогов недели взаимопомощи
