# Лига Помощников | Чат-бот и WebApp для мессенджера MAX

Проект разработан для Всероссийского хакатона **«Идея фикс»** (номинация *«Продвинутая разработка»*).  
**Команда:** Команда11 (ГАУДО РК «РЦДО», центр цифрового образования детей «IT-куб», г. Сыктывкар).

---

## О проекте

**«Лига Помощников»** — геймифицированный сервис для учебных чатов классов в мессенджере MAX:
* Школьники задают вопросы по учёбе командой `/ask <вопрос>`.
* Одноклассники отвечают реплаем и помогают с решением.
* Автор вопроса подтверждает помощь кнопкой «✅ Помог» в личном диалоге с ботом.
* Помощник получает +50 XP и +1 «спасибку» 🪙, а также открывает достижения.
* Звание ученика повышается: от *Новичка* до *Легенды школы*.
* Бот обращается к участникам по реальным именам и фамилиям.
* Управление в боте строится на интерактивных экранных кнопках (профиль, рейтинг, лавка, вызов справки, открытие WebApp).
* В WebApp доступна «Школьная лавка наград» от учителя, где спасибки обмениваются на бонусы.
* Для учителей предусмотрена поддержка нескольких классов (удобное переключение классов в WebApp), добавление наград и модерация заявок.

## Стек технологий

* **Язык и среда:** Python 3.14
* **Бэкенд:** FastAPI, Uvicorn, Pydantic v2
* **База данных:** SQLite (aiosqlite, SQLAlchemy 2.0 async)
* **Интеграция с MAX:** Асинхронный клиент MAX Bot API с Long Polling
* **Фронтенд:** Чистый HTML5, CSS3, JavaScript (дизайн-система Сферум / VK Community, адаптивный mobile-first WebApp)
* **Развертывание:** Docker, Docker Compose, Nginx (SSL Let's Encrypt)

## Запуск проекта

### 1. Подготовка окружения
Скопируйте пример файла конфигурации:
```bash
cp .env.example .env
```
Укажите ваш токен бота в переменной `MAX_BOT_TOKEN`.

### 2. Запуск через Docker (рекомендуется)
```bash
docker compose up -d --build
```
Просмотр логов:
```bash
docker compose logs -f
```
Остановка:
```bash
docker compose down
```

### 3. Локальный запуск через Python
```bash
pip install -r requirements.txt
python main.py
```
Приложение откроется на порту 8000. В браузере перейдите по адресу: `http://localhost:8000/`.

## Интерактивное управление и команды

* `[ 📱 Открыть WebApp ]` / `/start` — приветствие и запуск мини-приложения
* `/ask <текст>` — опубликовать вопрос в чате класса
* `[ ❓ Как спросить? ]` / `/help` — инструкция по использованию сервиса
* `[ 👤 Мой профиль ]` — просмотр личной статистики и баланса
* `[ 🏆 Рейтинг ]` — сводка лидеров
* `[ 🎁 Лавка ]` — просмотр доступных наград
* `[ 🎓 Кабинет учителя ]` / `/manage` — кабинет учителя для управления лавкой и одобрения заявок
